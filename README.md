# Five-a-side

A small, self-contained arcade football game that runs in a web browser. No installation or build step is required.

## Play

Open `index.html` in a modern web browser and select **Start match**.

## Controls

| Key | Action |
| --- | --- |
| W, A, S, D or arrow keys | Move |
| Space | Shoot when near the ball |
| Shift | Sprint; also adds power to a shot |
| R | Restart the match |

Score by shooting the ball into the opponent's goal before the 90-second timer expires. The opposing goalkeeper tracks the ball. Select **Restart match** below the pitch for a new match.
